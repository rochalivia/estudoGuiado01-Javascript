# 💜 Estudos de JavaScript: Variáveis, Arrays e Matrizes

Repositório de estudos de JavaScript, criado por Lívia Helena, com foco em lógica de programação. Cada exercício modela algo do mundo real em código.

## O que tem aqui

- 🐱 **Magrelinha**: variáveis (`const` e `let`), tipos primitivos e arrays simples.
- 💄 **Necessaire de maquiagem**: matriz em que cada linha é um produto e cada coluna é um dado dele.
- 🎧 **Playlist de estudo**: função que monta a linha, `push` para guardar na matriz e laço duplo para percorrer tudo.

## Conceitos praticados

- Variáveis e tipos: `string`, `number`, `boolean`, `undefined` e `null`
- Arrays e acesso por índice
- Matrizes e acesso por `[linha][coluna]`
- Funções com parâmetros e `return`
- Laços `for` aninhados com `length`

 ## Como rodar

Com o Node instalado, execute:
